Approved source: the in-chat proposed plan, explicitly requested for implementation on 2026-10-19. No external design document exists; this file records its implementation contracts.

## Global constraints
Preserve verified Nesine-only odds, user-selected archive source, source-only Sahadan initial H2H table, stable historical selection with ID/date, squad identity, current/recent/daily-feed/search order, themes and independent request lifetimes. No credentials or provider bodies in logs. Deploy on existing VDS and both static sites after verification. No paid services or external messages.

## Task 1: Durable store and team directory
Implement SQLite generic versioned records/cooldowns and verified team directory with suggestions and stable app IDs. Records return {value,savedAt,version}; missing/expired/version mismatch returns null. Default getReliabilityStore(): production ORAN_DATA_DIR/data.sqlite, tests/development memory. configureReliabilityStore(store) replaces singleton for tests/staging. DB durability, transactions and fail-closed corruption handling. TeamDirectory({store,searchProvider}) exposes async search(q) -> [{id,name,squad,country?}], async resolve({id,name}) -> team or null, observe({source,providerId,name,aliases?,squad?,country?}) -> team. Deterministic provider-scoped IDs unless evidence verifies cross-source merge. Search local exact/verified aliases then prefix/typo suggestions and source team search, max 8; no automatic fuzzy identity acceptance. Raw known unique names may resolve; user-selected IDs validated against record. Keep shared existing aliases. Default search provider Sahadan home-search via sourceJson, team type 1 and safe UUID only. Observe provider name/display names and squad. TDD with real DB temporary files and stubbed HTTP only.

Team fields use {id,name,squad,country?}; request optional homeTeamId,awayTeamId, supplied together or independently. IDs are opaque safe strings server validated by directory. Source IDs are never exposed as arbitrary fetch URLs. Persistent store only validated domain results plus team evidence/cooldowns; namespace/schema version isolates records. Archive result existing wire contract unchanged except optional archiveCache. Browser fallback status goes through same cooldown/host coordination or single serialized queue as bounded safety. Use better-sqlite3 pinned, ORAN_DATA_DIR=/var/lib/oran-analiz for production. Root installs dependencies; agents do not touch package manifests or commits. Root integrates and commits.
